# Eden Francavilla — Homepage Concept

Premium, mobile-first homepage concept for Eden Francavilla built around the positioning **“Coffee. Aperitivo. Mixology.”**

## Direction

- Dark editorial visual system
- Coffee → aperitivo → night-time mixology storytelling
- Responsive mobile-first layout
- Sticky mobile CTAs for booking, directions and Instagram
- Smooth reveal interactions and subtle pointer depth
- Verified public contact/location details only
- Cocktail examples are presented with a note that availability may vary

## Tech

Static HTML, CSS and vanilla JavaScript. No build step is required.

## Local preview

Open `index.html` directly or serve the folder with any simple local server.

## Deployment

The project can be deployed directly from the repository root on Netlify or GitHub Pages.
